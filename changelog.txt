Version: 0.0.6
Date: 2026-11-11
  Bugfixes:
    - Fixed the "Toggle visibility of tall entities" shortcut never becoming available: it still
      waited for the hidden Elevated rail technology. It now unlocks with Railway.
    - Fixed the "Elevated rails" tips-and-tricks entry never showing: its trigger now uses Railway.
    - Fixed existing saves where Railway was already researched: the Rail Planner could not switch
      to elevated rails (G) because the technology modifier was never applied. Recipes from other
      mods (e.g. Bob's) that end up in Railway are now applied as well.
    - Fixed any technology (also from other mods) that required Elevated rail being impossible to
      research. All such prerequisites are now replaced by Railway, not only rail-support-foundations.
  Changes:
    - All effects of the Elevated rail technology are now moved to Railway automatically instead of
      using a fixed recipe list, so additions from other mods are kept.
    - Bob's Logistics: the effects of its own elevated rail technology are moved the same way.
    - Removed duplicated code between vanilla.lua and mod-support.lua.
    - Thumbnail reduced to 144x144 (1.9 MB to 30 KB).
  Info:
    - Rail ramps and supports need refined concrete, which is unlocked by the Concrete technology.
      Railway does not require Concrete, so research Concrete before building elevated rails.
    - New release workflow: skips the upload correctly when the version is already on the portal and
      no longer packs development files.

Version: 0.0.4
Date: 2026-06-05
  Bugfixes:
    - FIXED: Rail supports could not be placed on Fulgora in the deep oil ocean.
      Cause: The technology "rail-support-foundations" required "elevated-rail".
      Since elevated-rail is disabled by the mod, rail-support-foundations could never
      be researched and the "rail-support-on-deep-oil-ocean" effect was never enabled.
      Fix: Replaced "elevated-rail" with "railway" in the prerequisites for rail-support-foundations.
    - FIXED: rail-planner-allow-elevated-rails modifier was missing in new games.
      The G-switch in the Rail Planner now works correctly after railway research.
  Changes:
    - New control.lua: Existing saves are automatically migrated on load.
      If railway or elevated-rail was already researched, all elevated-rail recipes are
      ensured to be enabled (idempotent, harmless if already active).
    - Code cleanup in vanilla.lua: removed conflicting rail-planner hidden assignments.
    - Updated prototypes/mod-support.lua: Fixed rail-support-foundations and
      rail-planner-allow-elevated-rails in mod compatibility code as well.
